# 核心概念

## 基本概念

- **数据库（Database）**：存储数据的容器，每个数据库可以包含多个集合（collection）
- **集合（Collection）**：存储数据的容器，每个集合可以包含多个文档（document），对应关系型数据库中的表
- **文档（Document）**：存储数据的基本单位，是一个由键值对组成的 BSON 对象，对应关系型数据库中的行
- **字段（Field）**：文档中存储的数据，每个字段都有一个键（key）和一个值（value），对应关系型数据库中的列
- **索引（Index）**：用于加速查询的特殊数据结构
- **聚合（Aggregation）**：用于对数据进行复杂操作的特殊查询（分组统计、多表关联等）

## 与关系型数据库对照

| MongoDB             | MySQL        | 说明                   |
| ------------------- | ------------ | ---------------------- |
| Database（数据库）  | Database     | 数据库                 |
| Collection（集合）  | Table（表）  | 存储文档的容器         |
| Document（文档）    | Row（行）    | 一条记录               |
| Field（字段）       | Column（列） | 记录中的一个属性       |
| `_id`               | Primary Key  | 主键，自动生成         |
| Embedded Document   | JOIN 外键    | 嵌套文档替代多表关联   |

## 数据结构示例

以电商业务为例，一个 MongoDB 实例中的数据层级如下：

```json
// MongoDB
{
  // 数据库 DataBase
  "DataBase": {
    // 集合 Collection，对应关系数据库中的表（table）
    "Collection": [
      // 文档 Document，对应关系数据库中的行（row）
      {
        // 字段 Field，对应关系数据库中的列（column）
        "Field": "Value"
      }
    ]
  },
  "京东": {
    "商品": [
      {
        "商品ID": "123456",
        "商品名称": "商品A",
        "商品价格": 100
      }
    ],
    "订单": [
      {
        "订单ID": "123456",
        "订单金额": 100
      }
    ]
  },
  "淘宝": {
    "商品": [
      {
        "商品ID": "789012",
        "商品名称": "商品B",
        "商品价格": 200
      }
    ]
  }
}
```

## BSON 与常用数据类型

MongoDB 内部使用 **BSON**（Binary JSON）格式存储文档，是 JSON 的二进制扩展，支持比 JSON 更丰富的数据类型：

| 类型               | 说明                                       |
| ------------------ | ------------------------------------------ |
| `String`           | UTF-8 字符串                               |
| `Int32` / `Int64`  | 32 位 / 64 位整数                          |
| `Double`           | 双精度浮点数                               |
| `Decimal128`       | 高精度小数，适合金额存储                   |
| `Boolean`          | 布尔值                                     |
| `Date`             | 日期时间（64 位毫秒时间戳）                |
| `ObjectId`         | 12 字节唯一标识符，`_id` 字段的默认类型    |
| `Array`            | 数组                                       |
| `Embedded Document`| 嵌套文档（子文档）                         |
| `Null`             | 空值                                       |

## `_id` 主键

每个文档都必须有一个 `_id` 字段作为唯一标识。插入文档时不指定 `_id`，MongoDB 会自动生成 **ObjectId**。

ObjectId 共 12 字节，构成如下：

```
4 字节         5 字节         3 字节
时间戳    +    随机值    +    递增计数器
（秒级）      （机器/进程）  （同一秒内保证唯一）
```

因此可以直接利用 `_id` 的前 4 字节按时间粗略排序，或提取插入时间：

```javascript
// mongosh 中获取文档的插入时间
ObjectId("653f1a2b3c4d5e6f7a8b9c0d").getTimestamp()
```
