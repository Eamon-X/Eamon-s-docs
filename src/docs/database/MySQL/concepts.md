# 核心概念

## 基本术语

| 术语   | 说明                                             |
| ------ | ------------------------------------------------ |
| 数据库 | 数据的仓库，一个 MySQL 实例可包含多个数据库      |
| 表     | 二维结构，由行和列组成，同一张表的列结构固定     |
| 行     | 一条记录，如一个用户的信息                       |
| 列     | 一个字段，有明确的数据类型与约束                 |
| 主键   | 唯一标识一行，非空且不重复，推荐自增整数         |
| 外键   | 引用另一张表的主键，用于维护表间关联             |
| 索引   | 加速查询的数据结构，类似书的目录                 |

## 数据类型

### 数值类型

| 类型         | 大小    | 说明                             |
| ------------ | ------- | -------------------------------- |
| TINYINT      | 1 字节  | 小整数，常用作状态位（0/1）      |
| SMALLINT     | 2 字节  | 较小整数，范围 -32768 ~ 32767    |
| MEDIUMINT    | 3 字节  | 中等整数，范围约 ±838 万         |
| INT          | 4 字节  | 最常用的整数，范围约 ±21 亿      |
| BIGINT       | 8 字节  | 大整数，如雪花 ID，范围约 ±922 亿亿 |
| BOOLEAN      | 1 字节  | TINYINT(1) 的别名，存 0/1 表示真/假 |

整数可加 `UNSIGNED` 属性去掉负数范围，如 `TINYINT UNSIGNED` 的范围为 0~255。

小数类型：

| 类型         | 大小    | 说明                                 |
| ------------ | ------- | ------------------------------------ |
| DECIMAL(M,D) | 变长    | 精确小数，**金额必须用它**；M 为总位数，D 为小数位 |
| FLOAT        | 4 字节  | 单精度近似值，约 7 位有效数字，存在精度丢失 |
| DOUBLE       | 8 字节  | 双精度近似值，约 15 位有效数字，存在精度丢失 |

### 字符串类型

| 类型       | 最大长度      | 说明                                    |
| ---------- | ------------- | --------------------------------------- |
| CHAR(N)    | 255 字符      | 定长，不足补空格，适合定长编码等        |
| VARCHAR(N) | 约 65535 字节 | 变长，最常用，N 为最大字符数            |
| TINYTEXT   | 255 字节      | 短文本                                  |
| TEXT       | 约 64 KB      | 长文本，不能设默认值                    |
| MEDIUMTEXT | 约 16 MB      | 更长的文本                              |
| LONGTEXT   | 约 4 GB       | 超长文本                                |
| ENUM       | 65535 个选项  | 枚举，取值限定在定义的列表内            |
| SET        | 64 个成员     | 集合，可同时选取多个值                  |
| BLOB 系列  | 同 TEXT 四档  | 二进制大对象，图片/文件建议存路径不存库 |

### 日期时间类型

| 类型      | 格式                | 范围                    | 说明                            |
| --------- | ------------------- | ----------------------- | ------------------------------- |
| DATE      | 2026-11-04          | 1000-01-01 ~ 9999-12-31 | 只有日期                        |
| TIME      | 12:30:00            | -838:59:59 ~ 838:59:59  | 只有时间，可表示时间间隔        |
| DATETIME  | 2026-11-04 12:30:00 | 1000-01-01 ~ 9999-12-31 | 日期 + 时间，8 字节，与时区无关 |
| TIMESTAMP | 时间戳              | 1970-01-01 ~ 2038-01-19 | 4 字节，随时区自动转换          |
| YEAR      | 2026                | 1901 ~ 2155             | 只有年份                        |

### 其他类型

| 类型   | 说明                                                   |
| ------ | ------------------------------------------------------ |
| JSON   | MySQL 5.7+ 原生 JSON，自动校验格式，可用 `->` 提取字段 |
| BIT(M) | 位类型，可存 0/1                                       |

> **注意**：金额用 `DECIMAL`；存日期推荐 `DATETIME`（`TIMESTAMP` 只能用到 2038 年）；`VARCHAR` 必须指定长度；拿不准时整数选 `INT`、字符串选 `VARCHAR` 基本不会错。

## 存储引擎

存储引擎决定数据的存储方式与支持的特性，MySQL 5.5+ 默认 InnoDB。

| 特性     | InnoDB               | MyISAM         |
| -------- | -------------------- | -------------- |
| 事务     | 支持                 | 不支持         |
| 外键     | 支持                 | 不支持         |
| 锁粒度   | 行级锁               | 表级锁         |
| 崩溃恢复 | 支持（redo log）     | 不支持         |
| 适用场景 | 绝大多数业务         | 只读、日志类表 |

```sql
-- 查看当前支持的引擎
SHOW ENGINES;

-- 建表时指定引擎
CREATE TABLE t (id INT) ENGINE=InnoDB;
```

> **注意**：日常开发统一使用 InnoDB 即可，MySQL 8.0 中 MyISAM 已无明显优势。

## SQL 语句分类

| 分类 | 全称                 | 作用         | 常见语句                    |
| ---- | -------------------- | ------------ | --------------------------- |
| DDL  | 数据定义语言         | 定义库表结构 | `CREATE`/`ALTER`/`DROP`     |
| DML  | 数据操作语言         | 增删改数据   | `INSERT`/`UPDATE`/`DELETE`  |
| DQL  | 数据查询语言         | 查询数据     | `SELECT`                    |
| DCL  | 数据控制语言         | 权限管理     | `GRANT`/`REVOKE`            |
| TCL  | 事务控制语言         | 事务管理     | `COMMIT`/`ROLLBACK`         |
