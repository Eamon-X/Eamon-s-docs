# 核心概念

## 基本术语

| 术语   | 说明                                             |
| ------ | ------------------------------------------------ |
| 数据库 | 数据的仓库，一个 MySQL 实例可包含多个数据库      |
| 表     | 二维结构，由行和列组成，同一张表的列结构固定     |
| 行     | 一条记录，如一个用户的信息                       |
| 列     | 一个字段，有明确的数据类型与约束                 |
| 主键   | 唯一标识一行，非空且不重复，推荐自增整数         |
| 外键   | 引用另一张表的主键，用于维护表间关联             |
| 索引   | 加速查询的数据结构，类似书的目录                 |

## 数据类型

### 数值类型

| 类型         | 大小    | 说明                             |
| ------------ | ------- | -------------------------------- |
| TINYINT      | 1 字节  | 小整数，常用作状态位（0/1）      |
| INT          | 4 字节  | 最常用的整数                     |
| BIGINT       | 8 字节  | 大整数，如雪花 ID                |
| DECIMAL(M,D) | 变长    | 精确小数，**金额必须用它**       |
| FLOAT/DOUBLE | 4/8 字节 | 近似小数，存在精度丢失问题      |

### 字符串类型

| 类型      | 说明                                    |
| --------- | --------------------------------------- |
| CHAR(N)   | 定长，不足补空格，适合定长编码等        |
| VARCHAR(N) | 变长，最常用，N 为最大字符数           |
| TEXT      | 长文本，不能设默认值                    |
| ENUM      | 枚举，取值限定在定义的列表内            |

### 日期时间类型

| 类型      | 格式                 | 说明                                  |
| --------- | -------------------- | ------------------------------------- |
| DATE      | 2026-11-03           | 只有日期                              |
| TIME      | 12:30:00             | 只有时间                              |
| DATETIME  | 2026-11-03 12:30:00  | 日期 + 时间，8 字节，与时区无关       |
| TIMESTAMP | 时间戳               | 4 字节，随时区转换，范围只到 2038 年  |

> **注意**：金额用 `DECIMAL`；存日期推荐 `DATETIME`；`VARCHAR` 必须指定长度。

## 存储引擎

存储引擎决定数据的存储方式与支持的特性，MySQL 5.5+ 默认 InnoDB。

| 特性     | InnoDB               | MyISAM         |
| -------- | -------------------- | -------------- |
| 事务     | 支持                 | 不支持         |
| 外键     | 支持                 | 不支持         |
| 锁粒度   | 行级锁               | 表级锁         |
| 崩溃恢复 | 支持（redo log）     | 不支持         |
| 适用场景 | 绝大多数业务         | 只读、日志类表 |

```sql
-- 查看当前支持的引擎
SHOW ENGINES;

-- 建表时指定引擎
CREATE TABLE t (id INT) ENGINE=InnoDB;
```

> **注意**：日常开发统一使用 InnoDB 即可，MySQL 8.0 中 MyISAM 已无明显优势。

## SQL 语句分类

| 分类 | 全称                 | 作用         | 常见语句                    |
| ---- | -------------------- | ------------ | --------------------------- |
| DDL  | 数据定义语言         | 定义库表结构 | `CREATE`/`ALTER`/`DROP`     |
| DML  | 数据操作语言         | 增删改数据   | `INSERT`/`UPDATE`/`DELETE`  |
| DQL  | 数据查询语言         | 查询数据     | `SELECT`                    |
| DCL  | 数据控制语言         | 权限管理     | `GRANT`/`REVOKE`            |
| TCL  | 事务控制语言         | 事务管理     | `COMMIT`/`ROLLBACK`         |
