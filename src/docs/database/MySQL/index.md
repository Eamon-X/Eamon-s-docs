# MySQL

## 简介

- MySQL 是一个开源的关系型数据库管理系统（RDBMS），使用 SQL 进行数据管理。
- 数据以表（行 + 列）的形式存储，支持事务、外键约束与多种存储引擎（默认 InnoDB）。
- 广泛用于 Web 应用，是 LAMP/LNMP 技术栈的重要组成部分。

## 安装 MySQL

[MySQL 官方下载](https://dev.mysql.com/downloads/)

### 验证安装

```shell
mysql --version
```
